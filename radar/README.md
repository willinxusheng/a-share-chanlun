# A股全市场缠论雷达 (radar/ · P2 行业视角)

对 **沪深A股 + 北交所 + 场内基金/ETF（约 7200 只）** 每日收盘后全量跑一遍缠论结构分析，
产出「近端背驰信号」与全市场结构索引，按**申万一级行业**聚合展示。

## 页面（三级导航 · 与主看板同宽 1160px · 深蓝渐变同款）

| 层级 | 路由 | 内容 |
|------|------|------|
| 一级 | `#/` | 状态胶囊 + 今日信号区 + 左「行业指数列表」右「行业缠论总览」 |
| 二级 | 点击行业 | 行业成分股**总市值加权合成K线**（缠论笔/中枢/背驰叠加，SVG矢量）+ 行业缠论结构 + 成分股信号分布 |
| 三级 | `#/stk/<sym>` | 个股详情：600px 主K线（浏览器实时拉腾讯 qfq 660根 + 缠论标注）+ 结构明细 |

- 顶背驰 = 红▼ / 底背驰 = 绿▲（A股约定：涨红跌绿），笔=紫折线、中枢=紫半透明矩形。
- K 线全部 ECharts **SVG 矢量**渲染（`renderer:"svg"`），MA5/10/20 + 量能副图 + 缩放。

## 行业维度（P2 新增）

- **行业归属**：东财 clist f100 返回**二级细分行业（129 个）**；`industry_map.py` 自建静态映射
  细分→申万一级 31（实测全 A+北交 **5566 股票零遗漏**，ETF/无行业标的归「-」不进行业聚合）。
- **行业K线合成**：`synth_industry_kline()` 成分股最新总市值定权 → 单日收益率加权 → 链式合成指数
  （基准 1000 起点，v=行业成交额/亿元），再复用 `chanlun.analyze` 做行业级缠论分析。
- 仅**通过门禁**的股票计入行业成分（信号分布与成分列表口径一致）。

### R445 行业口径纠错 + 低吸/趋势地基

三处**都必须同口径**（判据 / 排序 / 左侧色条 / 走势状态标签 / 说明文案），不得单改其一：

1. **信号集中度改「规模可比」口径**。`n_sig_top/bot` 是绝对数，但 32 个板块的成分数从
   16（综合）到 386（机械设备）**差 24 倍** ⇒ 绝对数排序被大板块恒定霸榜（实测 09-11：
   电子 15 个顶信号绝对第 4，摊薄后仅 4.1%；煤炭 6 个绝对第 15，密度却是全市场第一 20.7%）。
   改用 **95% Wilson 置信下界**（`_wilson_lb`，新字段 `sig_top_lb`/`sig_bot_lb`；原始密度
   `dens_top`/`dens_bot` 仅作展示）：小样本自动降权（22 只里 1 只原始密度 4.5%、下界仅 0.8%），
   无需人工设"最小样本量"门槛。**「显著集中」= 绝对只数 ≥ 2 且 下界 ≥ 2.5%**（`DENS_LB_STRONG`），
   排序按「主导方向下界×10 + 次方向×1」。实测 5 处「顶背驰区」虚标回落（交运 5/100、传媒 3/92、
   农林 4/82、建材 3/63、石化 3/42），色条点亮数 25 → 15。
2. **新增多周期动量 + 横截面相对强度**：`mom5/mom20/mom60`（合成指数近 N 根累计涨幅）、
   `rs20/rs60`（该板块动量在**同批 32 个板块**中的分位 —— 不用指数基准，R443 实证指数基准会把
   size/风格算进超额）、`accel`（5 日 vs 20 日日均涨幅差）、`rot`（轮动四象限）。
3. **新增"跌透度"**：`dd`（距近 250 根 ≈ 近一年最高价回撤）+ `pxq`（收盘价在近一年区间中的分位）。
   窗口 250 ≤ `IND_KLINE_N`(320) ⇒ 可由入库 kline 完整复算。
4. **默认排序改「📉 RSI 超卖优先」**（原默认「RSI 超买优先」与逆向视角方向相反）。

⚠️ 全部新增指标均为**描述性**（位置/动量/密度），不含买卖判断 —— 与 R443 回测结论一致
（顶背驰风险维度有效 −0.80pp p=0.018；底背驰机会未获证实 +0.58pp p=0.13）。

**前端兜底**：`indM()` 优先读后端字段，缺字段时用本页内嵌的 320 根行业 kline **就地同源复算**
（舍入链镜像后端），故 P3b-r18 之前构建的 radar.json 也能正确显示新列/新排序；
但「走势状态」标签由后端生成，旧数据下会与新手口径冲突，`#indRule` 会**如实列出冲突板块名**
并在下一次全市场重扫后自动消失（`regimeMismatch()`，只检测不复刻后端位置门控逻辑）。

**窄屏列数（R445 追加）**：新增第 5 列后行/表头各变 9 个子元素，`@media(max-width:980px)`
的旧 8 列覆盖必须同步（否则末列被挤进隐式第二行：实测 900px 行高 203px、表头 113px 竖排）。
现 ≤980 为 9 列；≤760 沿用 `.stk-grid`（R393）先例隐藏非关键列（市值成分/近120日走势/净流入），
保留 板块·走势状态·动量位置·涨跌·RSI 五个实操列 + 箭头。1280/980/900/760/600/390 六档实测
「轨道数 == 可见子元素数」且无横向溢出。

### R446 四象限口径上屏（免追问）

四象限标签（领先加速/领先减速/落后转强/落后加速）此前只有一句「相对强度 × 动量变化」，
读者需追问含义。现把口径与含义**刻到页面上**，四处落地、同一事实源（`ROT_DEF` / `ROT_LINE`）：

| 位置 | 内容 |
|---|---|
| `#indRule` 说明条 | **图例**：四个彩色胶囊 + 短描述（强/弱 × 加速/减速）+ 实操读法，附纵/横轴定义 |
| 胶囊 `title` | 名称含义 + 「怎么读」+ 本板块当前 `rs20`/`accel` + 贴线警告 + 「仅方位语言」免责 |
| 「走势状态」表头 | `title` 指引：状态=后端标签 + 四象限胶囊；含义见图例、数值悬停可见 |
| 详情页 metric strip | 内联 `(20日分位 N% · 动量变化 ±x.xxpp/日 · 短描述)` —— 不依赖悬停（触屏无 native title） |

判据必须与后端 `_rot_quadrant` 逐字一致：**`rs20 >= 50` 为「领先」，`accel > 0` 为「加速」**，
`accel = mom5/5 − mom20/20`（日均涨幅之差，pp/日）。

**贴线标记（`ROT_LINE = 0.10`）**：`|accel| < 0.10` 的板块几乎不动却被硬切进某一象限
（实测 ETF板块 −0.017、电力设备 −0.011、机械设备 −0.079），用**虚线边框**标出 + `title` 说明
「象限归属区分度低」。虚线而非加文字：上一轮 9 列布局刚修过挤压，任何加宽都会复发。

⚠️ 措辞是**方位语言**（"入场区/减仓区/观察区"），不含买卖建议 —— 与 R443 结论保持一致
（底背驰机会未获统计证实）；图例明确写「四个名字只是方位，不是评级」。

**验证**：真 Chrome 断言 68 项 0 失败（含**渲染层** `getComputedStyle().borderStyle` ——
只看 class 会被 `.rc` 的 `border:1px solid` 优先级坑），线上态(r16)/后端字段态(r18) 各 68/0，
R445 回归 37/0 ×2 + 全局冒烟 10/0；窄屏 980/900/760/600/390 五档图例与说明条零溢出。
**顺带核实**：详情页 metric strip 32/32 板块均为 4 行 100px（**无余量**）⇒ 动量段数字粘连
（`5日-2.5%20日-9.7%`）是 R445 为防折行做的有意取舍，加间隔会折行，故保持不动。

## 段级标注与「是否背驰」提示（R495）

雷达三类 K 线（行业合成 / 个股 / ETF）与主界面使用**同一套标注标准**：

| 标注 | 图上表现 | 来源 |
|------|---------|------|
| 笔级买卖点 一/二/三/**类二** | 小号三角(13)，标签 `1买/2买/3买/类2买` | `mark.sig` ← `chanlun.find_signals` |
| 段级买卖点 段1/段2/段3/段类2 | **大号三角(15)**，标签 `段1买/段2买/段3买/段类2买` | `mark.segsig` ← `chanlun.find_seg_signals` |
| 笔中枢 / 段级中枢 | 紫带 / **青带** —— 色相刻意不同：两者级别不同、跨度差一个量级，混色会被读成"同一中枢画了两次" | `mark.zs` / `mark.segzs` |

**「最新 K 线是否背驰」提示条**（详情页头部，行业与个股共用 `bcBarHtml`）：

- 数据全部来自后端 `st.bc_state`（`scan_radar._bc_state_of`），前端**只呈现、不重算**；
  阈值 `gap_th / fresh_th / area_th` 随数据一并下发，前端不写第二份副本。
- **段级为主口径**：R443 五年重放里段级底背驰 20 日胜率 70.0%(p≈0.017)，是唯一过显著性、
  且唯一"当日可操作"的判据；笔级标签 45.9%（不如随机）⇒ 只作对照，不并列成两个平级结论。
- **两个「活跃」不是一回事**：`gap` = 距末段的**段数**（结构活跃度）；`days` = 端点距末根的
  **交易日数**（时间新鲜度）。实测上证 2026-09-18 那条段级底背驰 `gap=1` 而 `days=44`
  —— 只报 gap 会被读成"昨天刚出的"。
- 顶/底并存时取**更新的那一段**（与 `cl.pick_recent_bc` 同律），并把"并存"这一事实如实报出。
- 引擎语义**未变**（R495 只新增消费点，零回归对照：既有 25 个 st 键 + 4 个 mark 键逐键全等）
  ⇒ 当时 `meta.version` 不 bump（后由 R496 因产物契约变更 bump 到 `P3b-r30`）。

**R497：提示条按新鲜度四档 + 消灭两处静默**

- **标题带上新鲜度**：`刚出`（端点距末根 ≤ `fresh_th`）/ `已非新出`（活跃但更旧）/ `无活跃`（末根无）。
  R495 的标题**一律**写「段级底背驰 · 机会 / 顶背驰 · 风险」，只在末尾挂一个小「新」徽章
  ⇒ 端点已是几十个交易日前的**存量**背驰与刚出的**标题一模一样**，必被读成"刚出"。
  实测（`--limit 400` 冒烟 · asof 2026-09-18 · 394 只）：`刚出` 7.9% / `已非新出` 16.2% /
  `无活跃` 75.9% ⇒ **「会被误读的那批」是「刚出」的 2 倍**，不是边角情形。
  `seg.days` 实测 min=1 / p25=5 / 中位=10 / max=72 ⇒ "紧贴末根的新背驰"**真实存在**，也**不常见**。
- **末根 / 信号锚点并排对照**：只给"距今 N 个交易日"没有基准就无从判断。现在同时给末根日期
  （`st.last`）与锚点日期（`seg.date`）：`刚出` 写「端点紧贴末根，属末根附近新长出的背驰」，
  `已非新出` 直接写「**不是最新 K 线上的新信号**（结构窗口内仍活跃）」。
- **`stale` 也保留淡方向色**（顶淡红 `#eda3a3` / 底淡绿 `#7ecfa6`）—— 纯白底会让整卡看不出
  顶底，方向只剩标题文字色一个线索。区分靠**饱和度 + 边框**：`fresh` = 饱和渐变 + 6px 实线；
  `stale` = 极淡渐变 + 4px 虚线。
- **两处静默改为显式**（本轮真正修的 bug）：`bcBarHtml` 的 `if(!bs)return ""` 与 `refreshBcBar`
  的 `_st?bcBarHtml(_st):""` —— 二者都会让用户在**新 HTML + 旧 JSON** 的部署窗口里看到
  "一条提示都没有"，**无法区分「没有背驰」与「没拿到数据」**（两者结论相反）。现改为 `nodata`
  态并明写「**这不等于「没有背驰」**」。注意这与"空态的 `无活跃`"是两个不同结论，不可合并。
- 覆盖路径（**四条全部实跑实证**）：`showStk`（个股 / 具体 ETF）、`pickInd`（行业 / **ETF板块**，
  走 `#bcBarWrap`）、以及 `pickInd` 后经 `switchTab`/`pickStkInInd` 切到个股 tab ——
  提示条随之换源（实测由行业的 `none` 换成个股的 `bot fresh`），保证**图与结论同源**。
- 呈现层改动，**后端零改动** ⇒ `meta.version` 不动（仍 `P3b-r30`）。

## 信号口径（P0 定论：近端窗口，非全历史尾笔）

- `classify` 近端场景 ∈ {背驰见底机会, 背驰见顶风险} **且** 对应背驰发生在最近 10 笔内、
  距背驰日 ≤ 10 交易日。
- 强信号 = 趋势背驰 或 段级同步；量能确认为附加置信。
- 排序：强信号优先 → 新鲜度 → 面积比。

## 用法

```bash
python3 radar/scan_radar.py --src sina --limit 200   # 本地冒烟(新浪源快; 腾讯源被WAF时)
python3 radar/scan_radar.py                          # 全量, CI 默认(腾讯qfq优先)

```
